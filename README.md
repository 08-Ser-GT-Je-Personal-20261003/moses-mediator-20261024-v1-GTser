## 内容

保留原题：“摩西作为旧约的中保为以色列百姓的罪代赎”。三点：他为什么献上自己、他怎样献上自己、他献上自己的结果。

15个主章节，约一万汉字；包括历史与写作背景、逐节解释、原创讲章、救赎历史与圣约关联、罪—救赎—感恩框架、三信经历史与教义对比、三项联合信条条文导读、12道详细讨论答案、区域示意图、时间线、背诵卡片、设备语音朗读及打印支持。

重要释经边界：摩西献己是代求中的意愿，不是神已接受的赎罪祭；基督独有、一次成全的救赎不可与摩西的请求混同。年代与地理不确定性明确标注。

信经短引唯一来源为 https://ccifellowship.org 。原站《敬拜手册》2015版保留中文译文转载权，全文重印授权尚待本次用户确认；因此当前版本**不重印三份信经或三项联合信条全文**。三份独立清简导读提供逐字短引、原创背诵路线与指定网站全文链接。不会以改写文本冒充原文。原站设置跨站嵌入限制，不采用失效的 iframe。

《出埃及记》中文和合本为公共领域；文内经文链接至 Bible Gateway 的 CUVS。讲章、解说、讨论、意象图与区域图为本项目原创编排。参考网页均在网站末章标明。外站文献不代表对本网站的认可。

## 本地生成与维护

需要 Python 3.9+，不需要第三方依赖：

```sh
python build.py
python verify.py
python -m http.server 8765 --directory dist
```

`content.json` 存储讲章；`study.json` 存储比较、信条导读与讨论。`build.py` 生成 `dist/` 静态网站。修改后重新生成并提交。GitHub Actions 自动部署 `dist/` 到 Pages；Surge 可对 `dist/` 另行部署。所有资源采用相对路径，兼容 Pages 子目录。

不在仓库或部署产物中保存账号密码、令牌或环境文件。设备朗读是否可用取决于系统中文语音。

版本：v1 · 2026-10-24（Asia/Taipei）。布局与交互检查见 `qa/report.json`。
